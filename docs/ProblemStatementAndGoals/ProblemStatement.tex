\subsection{Hardware Environment}

The simulator will run on a compatible VR headset capable of supporting real-time 3D applications. The headset will provide the display and motion tracking required for the user to interact with the simulated environment. VR controllers or compatible FPV flight controls will be used to control the simulated drone.

\subsection{Software Environment}

The simulator will run on the VR headset using a VR-compatible operating system and runtime environment. The software will require the necessary VR support to provide real-time graphics, motion tracking, and user input. The simulator will operate as a standalone VR application on supported hardware.


\section{Goals}

\begin{enumerate}
    \item Provide a realistic FPV drone flight experience in a virtual reality environment, maintaining a smooth and consistent frame rate throughout normal gameplay.

    \item Allow new users to learn basic FPV flight skills, demonstrated by their ability to complete a beginner course with progressively fewer crashes over repeated attempts.

    \item Allow experienced pilots to refine their flight skills, demonstrated through improvements in course completion times, flight consistency, and number of crashes.

    \item Provide responsive and intuitive flight controls, with minimal delay between controller input and corresponding drone movement.

    \item Provide realistic drone flight behaviour, with consistent responses to throttle, pitch, roll, and yaw inputs.

    \item Provide multiple environments and courses that expose users to different layouts, obstacles, and flight challenges.

    \item Record basic flight performance information, including completion times, crashes, and course completion status, for users to review their progress.
\end{enumerate}

\section{Stretch Goals}

\begin{enumerate}
    \item Provide multiple drone configurations with noticeably different flight characteristics and handling.

    \item Provide multiplayer functionality that allows multiple users to fly drones within the same virtual environment.

    \item Provide AI-based analysis of controller actions to identify patterns in a user's flying, such as inefficient inputs, inconsistent control, or excessive corrections.

    \item Provide AI-generated feedback that identifies areas for improvement based on the user's controller inputs and flight performance.
\end{enumerate}
